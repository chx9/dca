# 美股定投小红书封面 · moxia 风格

封面尺寸 1080×1440（3:4，小红书竖版），实际导出 2160×2880（2 倍图，缩略图更清晰）。

视觉语言取自墨匣（moxia）的主题：暖白底色 `#fafaf8`、粗衬线大标题、字距拉开的眉标、发丝细线、克制的点缀色、黑底页脚带。

## 风格

目前启用四个主题，共用同一份 JSON：

- `press` 小红书封面：黑白报刊 + 中国红、粗衬线大标题
- `panel` 账户月报（瑞士极简）：报头报脚沿用封面（红眉标 + 黑底页脚带），背景同为 `#fafaf8`；三列白卡，一列一只标的：标的名称居中，下方「本期定投 / 累计投入 / 浮盈+收益率」三组数字与名称同轴居中，底部浅灰三栏总览。深海军蓝 + 红涨绿跌，无渐变无阴影
- `trend` 近一月走势：真实行情曲线（三只按首日收盘归一），底部明细表兼图例。数据来自 `node fetch-quotes.mjs`，没有数据时显示「暂无数据」
- `wechat` 公众号头图（2.35:1）

墨韵（宣纸 + 朱砂）和森屿（森林绿 + 奶油白 + 焦糖金）的实现仍保留在 `build.mjs` 里，想换回来把对应主题加进 `THEMES` 对象即可。

## 网页生成器（最省事，推荐）

```bash
cd ~/Project/xhs/covers
node app.mjs           # 默认 4330，端口占用会顺延
```

打开 http://localhost:4330 ，填表点「生成封面」即可，不用碰 JSON：

- 填**第几期**（默认自动取下一期）、**定投第一天**（默认 2026-11-05）、走势天数（默认 30 天）
- 三只标的各填**本期定投 / 累计定投 / 当前市值**，一律填**美元**；服务器自动拉
  [frankfurter.dev](https://api.frankfurter.dev/v2/rate/USD/CNY) 的 USD→CNY 汇率换成人民币出图
  （接口挂了用当天缓存，也可手动覆盖汇率）。当前市值不填，浮盈那栏显示「暂无数据」
- 生成时会自动写 `issues/<期号>.json`（人民币值 + 美元原值 + 汇率都留着）、拉最近 N 天行情（走本地缓存，只补新交易日）、
  跑完整构建，页面上直接预览四张图并可下载
- 「第 N 天」按生成当天和第一天的间隔自动算

## 热更服务器（调版式时用）

```bash
cd ~/Project/xhs/covers
node serve.mjs          # 默认 4321，端口占用会顺延
```

打开 http://localhost:4321 。之后编辑 `issues/*.json` 或 `build.mjs` 并保存，服务器会自动重新渲染并在浏览器里刷新，不用手动跑命令。


## 行情数据（走势图用）

```bash
cd ~/Project/xhs/covers
node fetch-quotes.mjs 001                        # 默认取上一个自然月
node fetch-quotes.mjs 001 2026-10-01 2026-11-01  # 或手动指定区间
```

脚本把三只标的的收盘价写进 `data/001-quotes.json`，再 `node build.mjs 001` 就会多出一张 `001-trend.png`。
抓完之后热更服务器也会自动重画（它在监听 `data/`）。

- **本地缓存**：`data/quotes-cache.json` 按标的存 `{日期: 收盘价}`。每次**只请求最新缓存日期之后的新交易日**，已有日期一律不重抓；
  首次运行会用 `data/` 里已有的 `*-quotes.json` 自动回填，历史不用重拉。
- **双源**：首选东方财富日 K（`push2his.eastmoney.com`，前复权、免 key）；东财不可达（限流/被拒时会直接挂断连接）时，
  本次运行自动切到 **Nasdaq 官方 API** 兜底，同一天的收盘价两边一致。图上的「数据来源」会跟着变。
- **市场编号**：写死在 `fetch-quotes.mjs` 顶部的 `MARKET` 里 —— `105` 纳斯达克、`106` 纽交所、`107` NYSE Arca；
  Nasdaq 兜底的 `assetclass` 在 `NASDAQ_CLASS` 里（`etf` / `stocks`）。加新标的两处都要补。
- **只取收盘价**，涨跌幅在 `build.mjs` 里按「区间首日收盘价 = 0%」归一算出，不估算。
- 三只标的必须都有报价的交易日才会进入图表（取交集），避免某只停牌把曲线画歪。
- 每条序列还带一个 `prev`（区间前一日的收盘价），用来算区间第一天的「当日涨跌」；任何一只拿不到都**不覆盖旧文件**。

## 交互走势页（鼠标悬停看每日涨跌）

`node serve.mjs` 起来之后打开 **http://localhost:4321/trend.html** ：

- 和 `trend` 图片同一份数据、同一套视觉（`data/<期号>-quotes.json`）
- 鼠标划过（或手指点按）出现十字线，吸附到最近交易日，浮层列出三只标的当天的**收盘价、当日涨跌、区间累计涨跌**
- 键盘也能用：方向键左右移动，Esc 收起
- 图下方有完整明细表，不用鼠标也能读到每个值
- 换期号加参数：`trend.html?issue=002`

没跑 `fetch-quotes.mjs` 时页面会显示「暂无数据」并提示命令。直接双击打开文件（file://）读不到数据，必须经过本地服务器。

每次构建还会生成 `gallery.html`（双击用浏览器打开）：所有期数、所有主题平铺展示，点图片放大，点「保存封面」直接存图，「下载全部」一次保存，`out/covers.zip` 是原始 PNG 打包。新加一期后重新构建，网页自动更新。

## 做下一期

复制 `issues/001.json` 为 `issues/002.json`，改这几项即可：

```json
{
  "issue": 2,                       // 期数 → 右上角"第 02 期"
  "date": "2026.12",                // 计算天数用，格式 YYYY.MM
  "start": "2026-11-01",            // 第一次定投的日期 → 自动算"第 N 天"
  "title": ["*十年定投*", "~纳指、伯克希尔、SCHD"],
  "kicker": "标题下面的一行小字",
  "handle": "@你的小红书号",          // 底部右
  "tickers": ["IQQ", "BRK.B", "SCHD"],
  "stats": [
    { "label": "本期定投", "value": "6,000", "prefix": "¥" },
    { "label": "累计定投", "value": "12,000", "prefix": "¥" }
  ],
  "holdings": [                     // 看板 / 面板用；填每只的本期定投、累计投入和最新市值
    { "name": "纳指", "ticker": "IQQ", "period": 3000, "invested": 3000, "value": 3072.6, "shares": 12.5 },
    { "name": "伯克希尔", "ticker": "BRK.B", "period": 2000, "invested": 2000, "value": 2015.4, "shares": 4.2 },
    { "name": "高股息", "ticker": "SCHD", "period": 1000, "invested": 1000, "value": 993.8, "shares": 10.3 }
  ],
  "dividend": 0                     // 累计收到的现金分红，不填就显示「暂无数据」
}
```

> 「账户面板」里任何一项没填都会显示**暂无数据**，不会瞎猜数字。`shares`（持有股数）和 `dividend`（累计分红）只有面板用得上。

> `holdings` 里浮盈和收益率都由 `value - invested` 自动算，不用自己填。三只共用一个比例尺画条，长度可以直接比。加起来的总投入/总市值要和 `stats` 里的累计定投对得上，否则两张图会打架。

> 标题上方会显示大号「第 N 天 · 第 X 期」。天数默认按 `start` 到 `date` 所在月份 1 号自动算；想手动指定就加 `"day": 37`。
> `title` 每行控制在 7 个汉字以内（含英文代码），超出会换行破坏版式。
> 标题里用 `*整行*` 让这一行使用点缀色，句中想强调单个词可用 `**词**`，行首加 `~` 让这一行缩到 72%，可以把三只标的压成一行。

然后 `node build.mjs 002`。
